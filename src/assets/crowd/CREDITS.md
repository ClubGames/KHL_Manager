# The arena crowd: recordings

Every file here is cut from recordings their authors released under **Creative Commons 0 1.0** (public domain
dedication, https://creativecommons.org/publicdomain/zero/1.0/): free for any use, commercial included, no credit
required. The authors are named anyway. Edits: trimmed, faded, re-encoded (24 kHz MP3, 48 kbit/s); the game
crossfades the loops itself and sets the levels.

| File | What | Source (CC0 1.0) |
|---|---|---|
| murmur.mp3 | the indoor crowd between the plays (30 s loop) | "basketball_crowd_noise_01.wav" (a quiet section) by joedeshon — https://freesound.org/people/joedeshon/sounds/264291/ |
| stands.mp3 | the louder stands when the play gets dangerous (7.5 s loop) | "Stadium Crowd" by stomachache — https://freesound.org/people/stomachache/sounds/274516/ |
| cheer.mp3 | the roar after a goal (13 s) | "AF Crowd Cheer Nat End .wav" by mglennsound — https://freesound.org/people/mglennsound/sounds/678546/ |
| applause.mp3 | applause (10 s) | "University Indoor crowd, auditorium, graduation, applause 1" by FOSSarts — https://freesound.org/people/FOSSarts/sounds/750566/ |
| ooh.mp3 | "ooh!" at a post or a big chance (2.6 s) | "Crowd Oooh.wav" by deleted_user_2104797 — https://freesound.org/people/deleted_user_2104797/sounds/324890/ |

The edited excerpts came by way of the CC0 crowd packs of the open-source games WorldOfExploration/legacy-league
(murmur, ooh), theoreaves/football (stands) and Psalmuel01/street-football (cheer, applause), which list the same
sources and licences.
