# Штаб и управление формой команды

## Где находится

- **Клуб → Управление командой**: диагностика последних 8 матчей, подготовка,
  работа с раздевалкой, штат и рынок тренеров. В кризисе (не менее 5 матчей,
  максимум 1 победа в последних 8) главная страница показывает предупреждение.
- **Ростер**: главный тренер и один ассистент выбранного клуба, включая соперников.
- Старые сохранения без штаба дополняются автоматически. Уже существующие
  штабы сохранений (включая исторический срез и ваши назначения) не заменяются.
  Для старта с обновлёнными реальными назначениями создайте новую карьеру
  с новым `roster.json`.

## Справочные и игровые данные

В `roster.json` внесены 44 реальных имени: главный и **один представитель**
ассистентов для каждого из 22 клубов. Это не полный тренерский штаб.
Справочный срез — **сезон 2026/27, по состоянию на 23.11.2026**.
Учтены осенние назначения, а не только летние объявления. Ссылки на
источники находятся в `source` каждой записи и в `src/game/coachData.ts`;
полная таблица и примечания — в [coaching-sources-2026.md](coaching-sources-2026.md).
Это фиксированный набор, без автоматической загрузки новостей.
В интерфейсе доступны ссылки «Источник».

**Рейтинги, распределение игровых профилей и зарплаты полностью условны.**
Они не являются реальной статистикой, сведениями о контрактах или объективной
оценкой тренеров. Профили исходных штабов распределены детерминированно для
разнообразия, а не выведены из реальных результатов. Начальный рынок из 10
свободных специалистов вымышленный и явно помечен. Уволенные реальные тренеры
также переходят на рынок. Другие клубы не теряют своих тренеров при вашем найме.

## Реальные последствия решений

- **Замена штаба** — компенсация 50% годовой зарплаты уходящего и 25% подписного
  бонуса новому. Главный: освоение системы падает до 40%; ассистент: не выше 70%.
  Каждый календарный день восстанавливается 3 пункта. Повторная замена на той же
  должности только через 30 дней. Автоматического повышения морали нет.
- **Зарплаты** — 1/365 годовой суммы за календарный день, из бюджета клуба,
  вне потолка зарплат хоккеистов. Все условия назначения видны до подтверждения.
- **Подготовка** — выбранный режим действует до изменения; эффект нарастает за
  3 календарных дня. Новый план начинает накопление заново. Атака (+3/−1),
  оборона (−1/+3), спецбригады (+7% к коэффициенту качества PP/PK, −1 атака),
  восстановление (−2/−1), баланс (0/0). Числа — пункты игровых рейтингов.
- **Нагрузка** — каждый сыгранный матч +8. Ежедневное уменьшение:
  баланс 4, атака 1, оборона/спецбригады 2, восстановление 9.
  Выше 50 начинается штраф. Восстановление дополнительно снимает 2 усталости
  вратарей в день, но не лечит травмы.
- **Поддержка** — +5 к морали основной команды, +4 доверие.
- **Видеоразбор** — +2 оборона на 7 дней, но −4 мораль и −3 доверие;
  недоступен при доверии ниже 45.
- **Командное мероприятие** — 3 млн ₽, +6 сплочённость, +3 мораль, −4 нагрузка.
  Между любыми двумя вмешательствами — общий перерыв 14 дней. В межсезонье
  вмешательства недоступны; контрактные решения и планы доступны.

Штаб влияет на атаку, оборону, качество бросков в большинстве/защиту в
меньшинстве, эффективный рейтинг вратаря и недельный прирост XP у U23.
Мотивация смягчает падение доверия после поражений. Победы повышают доверие
и сплочённость, поражения снижают их. Мораль, доверие и сплочённость теперь
также входят в общую игровую поправку. Веса навыков штаба: главный 65%,
ассистент 35%. Поправки атаки/обороны ограничены ±8, развития — ×0,85…1,18.

`coachingEffects` — единый чистый расчёт для UI и `buildSimTeam`, которым
пользуются **обе** ветки матча: просмотр и быстрая симуляция. Сам просмотр
панели ничего не списывает и не продвигает время. Значения показываются
до матча. Победы не гарантируются. Диагностика выдаёт ориентиры по форме,
а не утверждает, что знает единственную причину поражений.

ИИ пользуется теми же показателями и раз в неделю корректирует подготовку
по результативности/нагрузке. Бесплатных собраний или найма ИИ не получает.
Летний отдых сбрасывает нагрузку и временные эффекты, но сохраняет наймы и рынок.

## Формат ростера и сохранения

`teams[].coaches` — необязательный массив; поддерживаются роли `head` и
`assistant`. Пример минимальной пользовательской записи:

```json
{
  "coaches": [
    { "id": "custom-head", "role": "head", "name": "Мой тренер", "profile": "defense", "salary": 18000000, "fictional": true },
    { "id": "custom-assistant", "role": "assistant", "name": "Мой ассистент", "profile": "development", "salary": 8000000, "fictional": true }
  ]
}
```

Профили: `balanced`, `attack`, `defense`, `development`, `motivator`.
Можно явно задавать `attack`, `defense`, `special`, `development`, `motivation`
(40…95), `salary` (0…100 млн), `source` (HTTPS), `snapshot`.
Неполные/некорректные записи нормализуются; отсутствующая роль получает штатное
значение. Старые ID клубов распознаются через существующий справочник алиасов.
Состояние `team.management` и `state.coachMarket` входит в обычное сохранение,
экспорт, копирование и загрузку; повторная миграция не сбрасывает решения.
`rosterWithContracts` по-прежнему изменяет исключительно контракты игроков.

## Проверки

- `npx tsc --noEmit`
- `npx tsx scripts/coaching-test.tsx` — данные 22 клубов, пользовательские
  штабы, миграция, финансы, найм, пределы, cooldown, фокус, восстановление,
  диагностика 1 победы в 8 матчах, симуляция, развитие молодёжи, новый сезон, SSR.
- `npm run build`
- `node scripts/coaching-ui-test.cjs` — настоящие клики по собранному приложению
  в jsdom: вход в клуб, подготовка, подтверждение собрания и найма, ограничения,
  закрытие/повторное открытие браузера и сохранение решений. Требует
  `npm install --no-save --package-lock=false jsdom@26` (как старый UI smoke).
- Существующие `bundles-test`, `gm-test`, `live-test`, `save-test`, `logos-test`
  и `ui-smoke` проверяют отсутствие регрессий. Старые тесты, читающие
  `public/roster.json`, используют временную копию `public/rostfdfer.json`;
  после прогона она удаляется. Для IndexedDB save-test нужен `fake-indexeddb`.
