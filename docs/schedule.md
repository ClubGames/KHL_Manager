# Календарь регулярного чемпионата

`buildSchedule` (`src/game/schedule.ts`) строит календарь по формату КХЛ 2026/27
(22 клуба, по 11 в конференции, 68 матчей).

## Пары (`buildMatchups`)
- Каждый с каждым — 2 матча (дома и в гостях): 42 игры.
- Со своей конференцией — ещё 2 (итого 4): +20 игр.
- 6 дополнительных игр с соперниками «по выбору лиги»: сначала команды своего
  дивизиона, затем остальные из своей конференции (с каждым из них итого 5 встреч).
- Дома ровно половина матчей (±1).
- Без конференций (пользовательский ростер) или при другом числе матчей используется
  та же схема: полные двойные круги, затем дополнительные пары.

## Даты
- День 0 — 1 сентября. Первые матчи — в первую субботу с 3 сентября (5.09.2026),
  последние — около 20 марта.
- Паузы без матчей: ноябрьская неделя сборных (совпадает с мораторием на обмены),
  декабрьская, Матч звёзд (совпадает с `allStarTargetDay`) и февральская.
- Клуб не играет дважды в день и почти никогда два дня подряд, играет раз в 2–4 дня.
- Домашние серии и выезды — 2–4 матча (никогда больше 5), выезд по возможности
  проходит по одному региону. Встречи одной пары разнесены по сезону.
- Календарь детерминирован для сезона и меняется от сезона к сезону.

Проверка: `npx tsx scripts/schedule-test.ts` (`-v` — таблица по клубам).
Уже начатые сезоны в сохранениях не перестраиваются; новый календарь появится в новой
карьере или со следующего сезона.
